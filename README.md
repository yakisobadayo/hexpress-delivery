## Controls

| Action | Keyboard / mouse | Controller |
|---|---|---|
| Fly | Space / left click | A / RT |
| Drop package | Down / right click | B, X / RB |
| Start run | Space / click OK | A / Start |
| Back to menu | Esc | Select |
| Menu | Arrows + Enter, or mouse | D-pad / left stick + A |

Controller support uses [Input](https://github.com/offalynne/Input) (MIT license, see `datafiles/input_license.txt`).
